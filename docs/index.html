User guide

eightbar

Talk to Ableton Live in plain English. It writes the MIDI, arranges the track, and mixes it.

What it is

Eightbar sits beside a running Ableton Live set and turns what you ask for into real notes. Ask for a chord progression, a loop, a variation, or a whole six-minute arrangement — it decides the pitches, the voicing and the groove, and writes them straight into your project.

You never type note numbers. You say "a rising i–VI–III–VII in C minor over eight bars" and a music-theory engine works out the rest, applies voice leading so chords don't jump octaves, and hands back a track you can play.

It is not an EDM-only tool. Alongside house, techno, trance, DnB and dubstep it knows cinematic, trailer, classical, chamber, jazz, song, lo-fi and score forms — each shaped differently, none of them just a loop on repeat.

01Install

Eightbar has two halves: a Python engine you run, and a small script that lives inside Ableton. You install both once.

1 · The engine

# Python 3.12, using uv
uv venv && source .venv/bin/activate
uv pip install -e ".[dev]"

2 · The remote script, into Live

python install_remote_script.py
macOS note. The script installs into your User Library, at ~/Music/Ableton/User Library/Remote Scripts/AbletonAI. Do not put it inside Ableton's app bundle — on macOS Sequoia and later the copy looks like it worked, then the system quietly reverts the signed bundle and the script is gone by the next launch.

3 · Turn it on in Ableton

Quit and reopen Live, then open Preferences → Link, Tempo & MIDI → Control Surface and pick AbletonAI in any free slot. Editing the script later always needs a Live restart — Live only loads control surfaces at launch.

# confirm Live is listening on port 9878
python -m ableton_ai.cli --check

4 · Pick a model backend

claude-cliNo API keyneeds Claude Code on your PATH; uses claude -p

auto — the default — uses the API when a key is present and falls back to claude -p otherwise.

02Running it

There are three ways in. The desktop app is a narrow palette that floats beside Live; the web UI and the terminal are there when you want them.

# the web UI, at http://127.0.0.1:7817
python -m ableton_ai.server

# a terminal chat
python -m ableton_ai.cli

# one-shot, no session
python -m ableton_ai.cli "make a house loop in F minor"

In the terminal, /state, /arrange, /tools, /reset and /quit do what they say. In the desktop app, ⌥⌘E shows and hides the palette from anywhere, including from inside Live.

03Talking to it

Ask for music the way you'd ask a session player. Genre and key are enough — it infers tempo, progression, structure and articulation, does the work, and tells you what it chose.

  • "create me a MIDI chord progression rising in C minor"
  • "build a dark rolling tech-house loop at 128"
  • "here's my loop — arrange it for a 6-minute dance track"
  • "make four variations of the drums, bigger each time"
  • "add placeholder tracks for vocals and FX"

The four things it does

Generate. Chords with real voicings, basslines placed against the kick, drums, arps, melodies with phrase structure, hooks, build-ups, risers and impacts.

Vary. Mutation operators — thin, densify, half_time, stutter, octave_up — and named recipes like stripped, breakdown, pre_drop and climax. Ask for "a ladder of variations" and it fills consecutive clip slots, each bigger than the last.

Arrange. Say "arrange this" and it uses the tracks already in your set — it reads them, gives each a role, picks a form that fits, and lays it on the timeline. Sections land on whole eight-bar phrases, risers finish exactly on the drop, impacts hit the downbeat, and there's a bar of air before the drop so it arrives out of silence. It creates nothing you didn't ask for.

Build. Say "build me a track" for an empty set and it writes the whole thing: instruments on every track, parts with the right feel for the genre, a full arrangement with builds and drops, and a mix.

Eightbar keeps the model away from raw MIDI on purpose. It also picks Ableton's own stock instruments — Wavetable, Drift, Operator, Analog and the named presets under Sounds/ — chosen per role and genre, so a piano is a Grand for classical and a Wurli for lo-fi. Swap any of them by hand afterwards.

04Mix & master

Ask it to "mix", "master" or "mix/master" and it runs one pass that applies the ten moves a mix engineer would, in order, on the tracks you already have — and reports what it did. It adds no tracks and changes nothing you didn't put there.

  1. Gain stagingHeadroom on the master, nothing clipping into the chain.
  2. Balance and panLevels and stereo placement by role — kick, bass and lead centred, the rest spread for width.
  3. Subtractive EQHigh-pass everything that isn't the low end, and cut before you boost, so two sounds never fight for one frequency.
  4. Low-end monoSum the sub to mono so the bottom translates on club rigs and vinyl.
  5. SidechainDuck the sustained bed to the kick — gently, and never the drums or transients.
  6. CompressionOnly where dynamics need it: drums for punch, bass for consistency. Melodic parts get EQ and space, not gain reduction.
  7. Reverb & delay sendsSpace by role on return tracks — drums nearly dry, pads and leads wet.
  8. Master busCorrective EQ, gentle glue compression, then a limiter. Glue, not loudness.
  9. Loudness to targetMeasure the master and bring it to a club-ready level, true peak under the ceiling.
  10. Translation checkResample and flag anything that won't survive a phone or a small speaker.

You can still reach for one move on its own afterwards — "high-pass the pad", "less sidechain on the bass" — and it'll do just that.

05Troubleshooting

"Ableton did not respond"

Check the control surface is selected (Preferences → Control Surface → AbletonAI) and that Live's status bar reads listening on port 9878. Then python -m ableton_ai.cli --check.

Nothing plays

Generated MIDI is silent until the track has an instrument. Building a track loads one for you; if you only generated notes onto an empty track, load a device or ask it to.

My edit to the script did nothing

Live only loads control surfaces at launch. Quit and reopen Live after any change to the remote script.

Two "Ableton" scripts in the dropdown

Ours is AbletonAI on port 9878. An unrelated older AbletonMCP on 9877 may also be installed; they coexist — just pick AbletonAI.

Before you reload or restart Live, save. Live has no "unsaved changes" flag of its own and there's no undo across a restart — an unsaved session doesn't survive one.
